# Lab 3 team scripts

Run them from your clone of AutoSDV, in a terminal where direnv has loaded the
environment (`cd` into the clone), for example `lab3/record_map.sh`. Each script is a
few lines around one standard command; read it before you run it.

| folder | holds | in git |
|---|---|---|
| `lab3/map/` | your map: `pointcloud_map.pcd`, `lanelet2_map.osm`, `map_projector_info.yaml` | yes, commit it |
| `lab3/bags/` | recordings (mapping bag, replays, laps) | no |
| `lab3/glim/` | GLIM's output | no |

Teams 4-6 (car C): replace `car_b` with `car_c` in `mapping.sh`, `replay.sh` and `run.sh`,
and commit.
